# 2. 영문 대소문자 정렬하기 — 최적화판

## 원리: 계수 정렬

문자 종류가 대문자 26개와 소문자 26개로 고정되어 있으므로, 등장 횟수를 세고 순서대로 출력한다. 비교 정렬의 O(L log L) 대신 O(L + 52)로 처리할 수 있다. L은 입력 길이다.

예시 `ABcdCDef`는 대문자 A, B, C, D와 소문자 c, d, e, f를 각각 알파벳순으로 정렬해 `ABCDcdef`가 된다. 같은 문자가 여러 번 나오면 그대로 개수를 유지한다.

## 코드의 기능과 개선점

1. 문자열이 비어 있는지 확인한다.
2. `counts[52]` 배열 하나로 대문자와 소문자 개수를 센다.
3. 대문자는 `letter - 'A'`로 0~25번, 소문자는 `26 + letter - 'a'`로 26~51번에 저장한다.
4. 입력 길이와 똑같은 `char[] output`을 한 번 할당한다.
5. 배열 앞에서부터 개수만큼 문자를 채운 뒤 `Console.WriteLine(output)`으로 한 번에 출력한다.
6. 영문자 외의 문자가 있으면 오류 안내를 출력한다.

기존 코드도 계수 정렬이므로 계산 복잡도는 같았다. 이번 개선은 문자마다 콘솔을 호출하는 비용을 줄이는 데 있다. 이를 위해 O(L)의 출력 버퍼를 추가로 사용한다. 두 개의 개수 배열도 하나로 합쳤다.

## 실행 예시

```text
입력: ABcdCDef
출력: ABCDcdef

입력: zZaAbB
출력: ABZabz

입력: BBAaa
출력: ABBaa
```

시간은 O(L + 52), 추가 공간은 O(L + 52)다.
