# 4. 네 내각으로 만들 수 있는 사각형 분류하기

## 원리

사각형을 둘러싼 순서대로 네 내각을 도 단위로 입력받는다. 볼록 사각형의 각 내각은 0도보다 크고 180도보다 작으며, 네 각의 합은 360도여야 한다. 이 조건에 맞지 않으면 사각형을 만들 수 없다고 안내한다.

각도만으로는 변의 길이가 정해지지 않는다. 따라서 코드는 입력한 각도를 유지하면서 변의 길이를 적절히 선택했을 때 만들 수 있는 종류를 모두 출력한다.

## 분류 규칙

- **평행사변형**: 마주 보는 각이 각각 같다 (`A == C`, `B == D`).
- **마름모**: 평행사변형의 각도 조건을 만족하면 변의 길이를 모두 같게 정할 수 있으므로 가능 목록에 포함한다.
- **직사각형·정사각형**: 네 각이 모두 90도이면 직사각형이며, 변의 길이도 같게 선택할 수 있으므로 정사각형도 가능 목록에 포함한다.
- **연꼴**: 마주 보는 각 중 한 쌍이 같으면 (`A == C` 또는 `B == D`) 변의 길이를 알맞게 정해 연꼴을 만들 수 있다. 이 분류에서는 마름모도 연꼴에 포함한다.
- **사다리꼴**: 이웃한 두 각의 합이 180도이면 마주 보는 한 쌍의 변을 평행하게 만들 수 있다. 여기서는 평행사변형과 구분해 정확히 한 쌍의 변만 평행한 경우를 사다리꼴로 출력한다.
- **등변사다리꼴**: 사다리꼴의 밑각이 각각 같으면 등변사다리꼴도 출력한다.

입력 순서는 사각형 둘레를 따라가는 순서다. 예를 들어 `A, B, C, D`에서 `A`와 `C`, `B`와 `D`가 마주 보는 각이다.

## 예외 처리

1. `decimal.TryParse`로 숫자가 아닌 입력을 확인한다.
2. 각도가 0도 이하이거나 180도 이상이면 볼록 사각형의 각이 아니므로 생성 불가로 처리한다.
3. 네 각의 합이 360도가 아니면 생성 불가로 처리한다.
4. 메인 메서드에서 입력 형식, 숫자 범위, 사각형 생성 오류를 잡아 안내 문구를 출력한다.

## 실행 예시

```text
입력: 90, 90, 90, 90
생성 가능한 사각형 종류:
- 사각형
- 평행사변형
- 마름모
- 직사각형
- 정사각형
- 연꼴
```

```text
입력: 75, 75, 105, 105
생성 가능한 사각형 종류:
- 사각형
- 사다리꼴
- 등변사다리꼴
```

각도 네 개만 비교하므로 시간과 추가 공간은 모두 O(1)이다.
