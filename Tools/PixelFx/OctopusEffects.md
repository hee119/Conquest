# 문어왕 패턴 이펙트

`Assets/PixelFx/Sheets/conquest`의 각 폴더에 투명 PNG 시트, 프레임 JSON,
Unity 애니메이션, 컨트롤러, 재생용 프리팹이 있습니다. 전부 24 FPS / 100 PPU입니다.

| 폴더 / 프리팹 이름 | 용도 | 재생 |
| --- | --- | --- |
| `hydro-pump` | 입에서 발사하는 압축 물줄기, 빈 틈과 끝 거품 없는 물살 | 반복 |
| `water-cannon` | 지름 약 30px의 둥근 물대포, 짧은 물방울 꼬리와 내부 물결(외부 흰 띠 없음) | 반복 |
| `radial-stone-eruption` | 중심부터 3개의 원형 파동으로 갈라지는 바닥과 솟아오르는 돌 | 약 2.27초 |
| `water-bomb` | 지름 약 60px의 큰 물덩어리와 떠 있는 세 줄의 잔잔하게 흐르는 흰 물띠 | 반복 |
| `water-cannon-impact` | 작은 착탄 물보라 | 약 0.97초 |
| `water-bomb-impact` | 넓은 물막과 물방울이 터지는 큰 착탄 물보라 | 약 1.34초 |

물줄기는 오른쪽(+X)을 향하며 피벗은 입구입니다. 입 위치에 배치한 후 부모나
Transform을 회전시키면 됩니다. 물대포·물폭탄의 피벗은 구체 중심이고,
지면 파쇄·착탄의 피벗은 바닥 중심입니다. 워닝 사인은 포함하지 않았습니다.

반복 이펙트는 공격 종료나 충돌 때 게임 쪽에서 끄고, 단발 이펙트는
`PixelFxEffect`가 끝나면 풀에 반환하거나 비활성화합니다.
예측 조준, 한 바퀴 회전, 낙하 궤적, 공격 범위·타격 횟수 및 피해 판정은
보스 패턴 코드가 담당하며, 문어왕과 기존 공격 프리팹에 모두 연결했습니다.

## 크기와 원형 파동 수 변경

단순한 크기 조절은 프리팹 인스턴스의 Transform Scale을 사용합니다.
지면 이펙트의 시각적 반지름과 파동 수는 원본을 다시 생성할 때도 지정할 수 있습니다.
`radius`는 픽셀 단위 24~130, `rings`는 1~4입니다.
`rings`는 한 번의 공격 안에서 솟는 돌의 원형 파동 수이며, 바닥을 치는 횟수와는 별개입니다.

```sh
node Tools/PixelFx/export.mjs conquest/radial-stone-eruption --import --ppu 100 --opts '{"radius":130,"rings":3}'
```

모든 원본은 `Tools/PixelFx/vendor/src/fx/conquest`에 있으며,
`node Tools/PixelFx/vendor/tools/check.mjs conquest`로 경계·반복 연결·종료 검사를 수행할 수 있습니다.
미리보기는 `python3 Tools/PixelFx/preview-octopus.py`로 다시 만듭니다(Pillow 필요).
결과는 `Tools/PixelFx/records/octopus`에 저장됩니다.

물대포와 물폭탄 내부에는 흰 물결이 가지를 치며 이어지는 무늬가 은은하게 출렁입니다.
물폭탄의 외부 흰 물띠 3개와 별도로 움직이며, 내부 무늬는 시드에 따라 다른 형태로 생성되며, 공의 회전과 별도로 파도가 이동하고 두께·간격이 변합니다. 물덩어리는 둥근 외곽을 유지하며 Y축을 중심으로 왼쪽으로 약 4초에 한 바퀴 도는 입체 회전 모습입니다. 내부 무늬는 구면 좌표로 감싸 옆으로 돌아가며, 하늘색 빈 공간은 이전보다 좁혔습니다.
두 구체의 최신 비교 미리보기는 `python3 Tools/PixelFx/preview-water.py`로 갱신합니다.

물 구체는 밝은 하늘색·청록색 중심, 진한 파란 하단 음영, 고정된 좌상단 반사를 사용합니다. 내부 흰 물결에도 조명에 따른 밝기 차이를 적용해 입체감을 냅니다.

하이드로 펌프의 말린 파도 끝 모양은 취소했습니다. 끝은 기존에 갈라져 흐르는 물살 모양을 유지하고, 물살 사이 투명한 틈을 같은 색의 물로 채운 형태입니다.

물대포는 외부 흰 띠 없이 내부 물결과 Y축 회전·현재 색감/깊이감이 있는 버전으로 사용자 확정했습니다.

하이드로 펌프 끝에 붙은 흰 거품과 주변으로 튀는 물방울 입자는 제거했습니다.

## 보스 적용

- `Assets/Resources/Prefabs/Boss/OctopusKing.prefab`의 `Mouth`가 애니메이션별 입 위치를 추적합니다.
- 하이드로 펌프 ID 1000: 입에서 한 바퀴 회전. `rotationSpeed`, `rotationCount`로 조절합니다.
- 연속 물대포 ID 601: 발사 애니메이션 10프레임(0.25초)에 입에서 발사합니다. `bulletSpawnCount`, `bulletSpawnInterval`로 조절합니다.
- 지면 파쇄 ID 1001: 내리치기 0.333초에 발밑에서 생성합니다. `groundAttackRadius`, `groundStrikeCount`로 범위와 타격 횟수를 조절합니다.
- 물폭탄 ID 602: 입에서 위로 포물선을 그리며 날아가고, 기존 워닝 사인 ID 1002의 위치에 착지합니다.
- 작은/큰 착탄 물보라는 풀 ID 1003/1004이며 `PatternData.csv`에 등록했습니다.
- 기존 공격의 피해량을 유지하고, 새 그래픽과 충돌 범위를 함께 맞췄습니다.
- `OctopusRuntimeVerification.json`은 별도 씬에서 실행한 입 추적, 6연발, 지면 범위·반복, 물폭탄·착탄 및 풀 반환 검증 결과입니다.
- `ApplyOctopusEffects.cs`는 편집 모드에서 실행하는 적용 스니펫입니다. 현재 프리팹은 이미 적용된 상태입니다.
