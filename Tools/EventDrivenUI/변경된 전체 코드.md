# 이벤트 기반 UI 사운드와 SPUM 입력 변경

## 사운드 흐름

`버튼/토글 → UiSoundEmitter → UiSoundEvents → SoundManager → AudioSource`

- `SoundManager.Update()`의 UI 검색, 0.15초 스캔 타이머, 전역 메뉴/패널 탐색을 제거했습니다. 기존 페이드·볼륨·일시정지 처리는 유지합니다.
- `UiSoundEmitter`가 활성화될 때 생성/등록 이벤트를 발행하고 버튼 클릭과 토글 변경을 전달합니다. 비활성화될 때 리스너와 등록을 해제합니다.
- `SoundManager`는 `OnEnable`에서 이벤트를 구독하고, 기존 활성 UI 등록 목록도 받아 생성 순서를 처리합니다. `OnDisable`/`OnDestroy`에서 해제합니다.
- 씬 로드 시 해당 씬의 UI 계층을 한 번 등록합니다. 주기적인 전역 탐색은 없습니다.
- 기존 프리팹 7개에 이벤트 발행 컴포넌트 8개를 등록했고, 동적 버튼 생성 코드에도 등록을 연결했습니다. 템플릿/프리팹 복제는 발행 컴포넌트를 그대로 상속합니다.
- 코드로 완전히 새로운 버튼/토글을 만들 때는 `UiSoundEvents.Register(control)`을 한 번 호출합니다. 새 UI 계층 전체에는 `UiSoundEvents.RegisterHierarchy(root)`를 사용합니다.
- 강화/확정/드롭다운/호버 UI도 이벤트를 발행합니다. 전용 사운드 버튼에는 기본 클릭음을 중복 재생하지 않습니다.

## 캐릭터 입력과 이동

`InputAction.performed → PlayerManager.HandlePointerPress → 선택 / PlayerObj.SetMovePos → 이동 코루틴`

- 변경 대상은 `Assets/GameAssets/SPUM/Sample/Script`에 있는 샘플 캐릭터 관리 코드입니다. 추가 요청에 따라 게임 본편 `PlayerMove`의 마우스 우클릭 대시도 이벤트 콜백으로 변경했습니다.
- `PlayerManager`는 포인터 누름 액션을 활성화/비활성화와 함께 구독·해제하고, 파괴 시 액션을 해제합니다.
- 입력 콜백에서 현재 화면 좌표를 `EventSystem.RaycastAll`로 검사합니다. GraphicRaycaster의 UI 결과가 있으면 캐릭터 선택/이동을 진행하지 않습니다. 입력 콜백의 `IsPointerOverGameObject`는 이전 프레임 UI 상태를 읽을 수 있으므로 사용하지 않았습니다. [Unity 공식 입력/UI 처리 설명](https://github.com/Unity-Technologies/InputSystem/blob/develop/Packages/com.unity.inputsystem/Documentation~/handling-input-target-ambiguity.md)
- 캐릭터 선택, 명령 패널, 애니메이션 미리보기, 생성/정렬, 스크린샷 공개 메서드를 유지했습니다.
- `PlayerObj`는 이동 명령을 전달받으면 코루틴을 시작하고 도착하면 종료합니다. 입력 액션은 Manager가 한 번 처리하며 각 캐릭터가 중복 구독하지 않습니다.
- X/Y 평면에서 MoveTowards로 이동해 목표를 지나치지 않습니다. 좌우 반전과 `localPosition.y * 0.01` 기반 월드 Z 정렬을 유지했습니다.
- 이동/대기 애니메이션은 상태 전환 시 한 번 실행합니다. 이동 중 목표만 바꾸면 이동 애니메이션을 다시 시작하지 않습니다. 수동 미리보기는 명시적으로 같은 애니메이션도 다시 재생할 수 있습니다.
- 선택 표시는 선택 시와 캐릭터의 `PositionChanged` 이벤트에서만 갱신합니다. 캐릭터 비활성화와 Manager 비활성화 시 구독을 해제합니다.
- 외부 코드가 캐릭터 Transform을 직접 변경할 경우 `RefreshPosition()`을 호출하면 Z 정렬과 선택 표시가 갱신됩니다. 기존 생성·정렬 명령에는 이 호출이 연결되어 있습니다.
- `isAction`은 호환 프로퍼티로 유지하며 기존 직렬화 값은 `FormerlySerializedAs`로 이관합니다.
- `PlayerManager`와 `PlayerObj`에는 `Update`, `FixedUpdate`, `LateUpdate`가 없습니다. 이동 중 코루틴만 프레임마다 필요한 위치 계산을 수행합니다.

## 검증

Unity에서 스크립트 컴파일을 확인하고 별도 씬에서 실제 입력 액션과 UI 콜백을 실행했습니다.
`RuntimeVerification.json`에 생성 순서, 동적/복제 UI, 중복 리스너, 토글 양방향, 구독 해제·재구독, 전용 확정음, 입력 선택·이동, UI 클릭 차단, 목표 변경, 좌우 반전, Z 정렬, 이동 종료, 유휴 위치 갱신 중단, 애니메이션 미리보기 결과를 기록했습니다. 모든 항목이 통과했고 실행 예외는 없었습니다.
원래 씬과 실행 시작 씬 설정을 복원했고 임시 검증용 런타임 컴포넌트와 씬은 제거했습니다. 검증 코드 사본은 이 폴더에 있습니다.

## 추가 요청: PlayerMove 마우스 대시

`PlayerMove`는 `<Mouse>/rightButton`에 연결된 `InputAction`의 `performed` 콜백에서 대시를 시작합니다. `OnEnable`에서 구독·활성화하고 `OnDisable`에서 해제·비활성화, `OnDestroy`에서 액션을 폐기합니다. 우클릭을 누르고 있는 동안 반복 발사되지 않고 새로운 누름마다 한 번 처리합니다.

기존 `Move(InputAction.CallbackContext)` 키보드 이동과 실제 Rigidbody 이동, 대시 회복, 타일맵 경계, 발소리는 유지합니다. `Update`, `FixedUpdate`, `LateUpdate`는 없습니다. 대시 입력이 대시 코루틴을 시작하고 종료 시 멈춥니다. 회복 코루틴은 에너지가 100이 되면 종료하며, 재대시 시 회복 대기를 다시 시작합니다. 경계 검사와 발소리는 실제 이동·대시 중의 물리 코루틴에서만 처리하며 정지 시 종료합니다. 컴포넌트 비활성화 시 세 코루틴 모두 중단합니다. 일시정지 상태와 비활성 PlayerInput의 대시 이벤트는 무시합니다. 가상 마우스로 우클릭·길게 누르기·재누르기·비활성화/재활성화·일시정지·대시 에너지 회복을 실행 검증했으며 결과는 `PlayerMoveInputVerification.json`에 기록했습니다.

```csharp
using System;
using System.Collections.Generic;
using UnityEngine;
using Sirenix.OdinInspector;

public sealed class SoundManager : MonoBehaviour
{
    private const string MasterVolumeKey = "Audio.MasterVolume";
    private const string BgmVolumeKey = "Audio.BgmVolume";
    private const string SfxVolumeKey = "Audio.SfxVolume";
    private const float SettingsBgmVolumeScale = 0.2f;

    private float bgmVolumeScale = 1f;
    private int settingsOpenCount;
    private bool upgradeSelectionOpen;
    private readonly List<AudioSource> stoppedLoops = new List<AudioSource>();
    private AudioSource bgmSource;
    private readonly List<OneShotVoice> oneShotVoices = new List<OneShotVoice>();
    private readonly Stack<AudioSource> availableOneShotSources = new Stack<AudioSource>();
    private readonly Dictionary<AudioSource, int> loopSoundIds = new Dictionary<AudioSource, int>();
    private readonly Dictionary<AudioSource, int> loopStartedFrames = new Dictionary<AudioSource, int>();
    private readonly Dictionary<AudioSource, EnemySoundLifetime> enemyLoopLifetimes = new();
    private readonly List<AudioSource> fadedLoops = new();
    private readonly HashSet<UiSoundEmitter> uiControls = new HashSet<UiSoundEmitter>();
    private int lastUiClickFrame = -1;
    private int lastUiHoverFrame = -1;
    [SerializeField, LabelText("사운드 목록")]
    [ListDrawerSettings(ListElementLabelName = "name", DefaultExpandedState = false, ShowIndexLabels = false)]
    private List<SoundEntry> sounds = new List<SoundEntry>();
    private readonly Dictionary<AudioSource, float> loopVolumes = new Dictionary<AudioSource, float>();
    public IReadOnlyList<SoundEntry> Sounds => sounds;

    private struct OneShotVoice
    {
        public AudioSource Source;
        public int SoundId;
        public float VolumeScale;
        public int StartedFrame;
        public EnemySoundLifetime Lifetime;
    }

    private sealed class EnemySoundLifetime
    {
        public EnemyCombat Enemy;
        public PooledObject Pool;
        public uint SpawnVersion;
        public float Duration;
        public float Elapsed = -1f;
        public float Gain = 1f;

        public bool Advance(float delta)
        {
            if (Elapsed < 0f)
            {
                if (Enemy != null && Enemy.gameObject.activeInHierarchy &&
                    !Enemy.isDead && Enemy.hp > 0f &&
                    (Pool == null || Pool.SpawnVersion == SpawnVersion))
                    return false;
                Elapsed = 0f;
            }
            Elapsed += delta;
            Gain = Mathf.Clamp01(1f - Elapsed / Duration);
            return Gain <= 0f;
        }
    }

    public static SoundManager Instance { get; private set; }
    public float MasterVolume { get; private set; } = 1f;
    public float BgmVolume { get; private set; } = 1f;
    public float SfxVolume { get; private set; } = 1f;

    public event Action<float> SfxVolumeChanged;

    private void Awake()
    {
        if (Instance != null && Instance != this)
        {
            Destroy(gameObject);
            return;
        }

        Instance = this;
        DontDestroyOnLoad(gameObject);

        MasterVolume = Mathf.Clamp01(PlayerPrefs.GetFloat(MasterVolumeKey, 1f));
        BgmVolume = Mathf.Clamp01(PlayerPrefs.GetFloat(BgmVolumeKey, 1f));
        SfxVolume = Mathf.Clamp01(PlayerPrefs.GetFloat(SfxVolumeKey, 1f));

        Transform authoredBgm = transform.Find("BGM");
        bgmSource = authoredBgm != null ? authoredBgm.GetComponent<AudioSource>() : null;
        if (bgmSource == null)
            bgmSource = CreateSource("BGM", true);
        AudioListener.volume = MasterVolume;
        AudioListener.pause = Time.timeScale <= 0f;
        ApplyBgmVolume();
    }

    private void Update()
    {
        bool upgradeOpen = LevelManager.Instance != null &&
            LevelManager.Instance.upgradeUI != null &&
            LevelManager.Instance.upgradeUI.activeInHierarchy;
        if (upgradeSelectionOpen != upgradeOpen)
        {
            upgradeSelectionOpen = upgradeOpen;
            ApplyBgmVolume();
        }

        // Time.timeScale pauses gameplay timing, but does not pause audio by itself.
        // Pause every AudioSource globally while gameplay is paused, then resume them.
        AudioListener.pause = Time.timeScale <= 0f;

        UpdateEnemySoundFades();
        CleanupStoppedLoops();
        CleanupFinishedOneShots();
    }

    private void OnEnable()
    {
        if (Instance != this) return;
        UiSoundEvents.Created += RegisterUiControl;
        UiSoundEvents.Removed += UnregisterUiControl;
        UiSoundEvents.Clicked += OnUiClicked;
        UiSoundEvents.ToggleChanged += OnUiToggleChanged;
        UiSoundEvents.Requested += OnUiSoundRequested;
        foreach (var control in UiSoundEvents.Controls) RegisterUiControl(control);
    }

    private void OnDisable()
    {
        UiSoundEvents.Created -= RegisterUiControl;
        UiSoundEvents.Removed -= UnregisterUiControl;
        UiSoundEvents.Clicked -= OnUiClicked;
        UiSoundEvents.ToggleChanged -= OnUiToggleChanged;
        UiSoundEvents.Requested -= OnUiSoundRequested;
        uiControls.Clear();
    }

    private void RegisterUiControl(UiSoundEmitter control) => uiControls.Add(control);
    private void UnregisterUiControl(UiSoundEmitter control) => uiControls.Remove(control);
    private void OnUiClicked(UiSoundEmitter control)
    {
        if (control != null && !control.SuppressDefaultClick) PlayUiClick();
    }
    private void OnUiToggleChanged(UiSoundEmitter control, bool value)
    {
        if (control == null) return;
        if (control.IsDropdownOption) { if (value) PlayUiConfirm(); }
        else PlayUiClick();
    }
    private void OnUiSoundRequested(UiSoundCue cue)
    {
        switch (cue)
        {
            case UiSoundCue.Click: PlayUiClick(); break;
            case UiSoundCue.Confirm: PlayUiConfirm(); break;
            case UiSoundCue.Hover: PlayUiHover(); break;
            case UiSoundCue.Upgrade: PlayOneShotIgnoringPause(SoundIds.UpgradeSelect); break;
        }
    }

    public void PlayUiClick()
    {
        // A dropdown row can also be a Toggle; emit only one click per action.
        if (lastUiClickFrame == Time.frameCount)
            return;
        lastUiClickFrame = Time.frameCount;
        PlayOneShotIgnoringPause(SoundIds.ButtonClick);
    }

    public void PlayUiConfirm()
    {
        // The dropdown callback and its option Toggle can fire in the same frame.
        if (lastUiClickFrame == Time.frameCount)
            return;
        lastUiClickFrame = Time.frameCount;
        PlayOneShotIgnoringPause(SoundIds.CharacterConfirm);
    }

    public void PlayUiHover()
    {
        if (lastUiHoverFrame == Time.frameCount)
            return;
        lastUiHoverFrame = Time.frameCount;
        PlayOneShotIgnoringPause(SoundIds.UiHover);
    }

    public void SetMasterVolume(float volume)
    {
        MasterVolume = Mathf.Clamp01(volume);
        AudioListener.volume = MasterVolume;
        PlayerPrefs.SetFloat(MasterVolumeKey, MasterVolume);
    }

    public void SetBgmVolume(float volume)
    {
        BgmVolume = Mathf.Clamp01(volume);
        ApplyBgmVolume();

        PlayerPrefs.SetFloat(BgmVolumeKey, BgmVolume);
    }

    public void BeginSettingsAudio()
    {
        settingsOpenCount++;
        ApplyBgmVolume();
    }

    public void EndSettingsAudio()
    {
        settingsOpenCount = Mathf.Max(0, settingsOpenCount - 1);
        ApplyBgmVolume();
    }

    private void ApplyBgmVolume()
    {
        if (bgmSource == null)
            return;

        bool selectionOrSettingsOpen = settingsOpenCount > 0 || upgradeSelectionOpen;
        bgmSource.ignoreListenerPause = selectionOrSettingsOpen;
        bgmSource.volume = BgmVolume * bgmVolumeScale *
            (selectionOrSettingsOpen ? SettingsBgmVolumeScale : 1f);
    }

    public void SetSfxVolume(float volume)
    {
        SfxVolume = Mathf.Clamp01(volume);
        foreach (var pair in loopVolumes)
            if (pair.Key != null) pair.Key.volume = pair.Value * SfxVolume *
                (enemyLoopLifetimes.TryGetValue(pair.Key, out var lifetime) ? lifetime.Gain : 1f);
        foreach (OneShotVoice voice in oneShotVoices)
            if (voice.Source != null) voice.Source.volume = voice.VolumeScale * SfxVolume *
                (voice.Lifetime != null ? voice.Lifetime.Gain : 1f);
        SfxVolumeChanged?.Invoke(SfxVolume);
        PlayerPrefs.SetFloat(SfxVolumeKey, SfxVolume);
    }

    public AudioSource Play(int id, float volumeScale = 1f, bool loop = false,
        bool bgm = false, bool restartIfPlaying = false, EnemyCombat enemy = null)
    {
        SoundEntry entry = sounds.Find(sound => sound != null && sound.id == id);
        if (entry == null || entry.clip == null)
        {
            Debug.LogWarning($"사운드 ID {id}의 파일이 등록되지 않았습니다.", this);
            return null;
        }

        volumeScale = Mathf.Clamp01(volumeScale);
        if (bgm)
        {
            if (!restartIfPlaying && bgmSource.isPlaying && bgmSource.clip == entry.clip)
                return bgmSource;
            bgmSource.Stop();
            bgmSource.clip = entry.clip;
            bgmSource.loop = loop;
            bgmVolumeScale = volumeScale;
            ApplyBgmVolume();
            bgmSource.Play();
            return bgmSource;
        }

        if (loop)
        {
            if (!CanStartVoice(entry))
                return null;
            volumeScale *= Mathf.Clamp01(entry.volume);
            AudioSource source = CreateSource(entry.name, true);
            source.clip = entry.clip;
            source.volume = SfxVolume * volumeScale;
            loopVolumes.Add(source, volumeScale);
            loopSoundIds.Add(source, id);
            loopStartedFrames.Add(source, Time.frameCount);
            var lifetime = CreateEnemySoundLifetime(entry, enemy);
            if (lifetime != null)
                enemyLoopLifetimes.Add(source, lifetime);
            source.Play();
            return source;
        }

        return PlayOneShot(entry, volumeScale, false, enemy);
    }

    public void PlayOneShotIgnoringPause(int id, float volumeScale = 1f)
    {
        SoundEntry entry = sounds.Find(sound => sound != null && sound.id == id);
        if (entry == null || entry.clip == null)
        {
            Debug.LogWarning($"사운드 ID {id}의 파일이 등록되지 않았습니다.", this);
            return;
        }

        PlayOneShot(entry, Mathf.Clamp01(volumeScale), true);
    }

    private AudioSource PlayOneShot(SoundEntry entry, float volumeScale, bool ignorePause, EnemyCombat enemy = null)
    {
        if (!CanStartVoice(entry))
            return null;

        // Keep the correction in the stored scale so slider changes preserve the balance.
        volumeScale *= Mathf.Clamp01(entry.volume);

        AudioSource source = null;
        while (availableOneShotSources.Count > 0 && source == null)
            source = availableOneShotSources.Pop();
        if (source == null)
            source = CreateSource("SFX", false);

        source.gameObject.SetActive(true);
        source.clip = entry.clip;
        source.loop = false;
        source.pitch = 1f;
        source.ignoreListenerPause = ignorePause;
        source.volume = SfxVolume * volumeScale;
        source.Play();
        oneShotVoices.Add(new OneShotVoice
        {
            Source = source,
            SoundId = entry.id,
            VolumeScale = volumeScale,
            StartedFrame = Time.frameCount,
            Lifetime = CreateEnemySoundLifetime(entry, enemy)
        });
        return source;
    }

    private bool CanStartVoice(SoundEntry entry)
    {
        CleanupStoppedLoops();
        CleanupFinishedOneShots();
        int count = 0;
        foreach (OneShotVoice voice in oneShotVoices)
            if (voice.SoundId == entry.id) count++;
        foreach (int soundId in loopSoundIds.Values)
            if (soundId == entry.id) count++;
        return count < Mathf.Max(1, entry.maxConcurrentVoices);
    }

    private static EnemySoundLifetime CreateEnemySoundLifetime(SoundEntry entry, EnemyCombat enemy)
    {
        if (!entry.fadeOnEnemyDeath || enemy == null)
            return null;
        var pool = enemy.GetComponent<PooledObject>();
        return new EnemySoundLifetime
        {
            Enemy = enemy,
            Pool = pool,
            SpawnVersion = pool != null ? pool.SpawnVersion : 0,
            Duration = Mathf.Max(0.01f, entry.enemyDeathFadeSeconds)
        };
    }

    private void UpdateEnemySoundFades()
    {
        for (int i = oneShotVoices.Count - 1; i >= 0; i--)
        {
            var voice = oneShotVoices[i];
            if (voice.Lifetime == null)
                continue;
            if (voice.Lifetime.Advance(Time.unscaledDeltaTime))
                ReleaseOneShot(i);
            else if (voice.Source != null)
                voice.Source.volume = voice.VolumeScale * SfxVolume * voice.Lifetime.Gain;
        }

        fadedLoops.Clear();
        foreach (var pair in enemyLoopLifetimes)
        {
            if (pair.Value.Advance(Time.unscaledDeltaTime))
                fadedLoops.Add(pair.Key);
            else if (pair.Key != null && loopVolumes.TryGetValue(pair.Key, out float scale))
                pair.Key.volume = scale * SfxVolume * pair.Value.Gain;
        }
        foreach (var source in fadedLoops)
            Stop(source);
    }

    private void ReleaseOneShot(int index)
    {
        var source = oneShotVoices[index].Source;
        oneShotVoices.RemoveAt(index);
        if (source == null)
            return;
        source.Stop();
        source.clip = null;
        source.gameObject.SetActive(false);
        availableOneShotSources.Push(source);
    }

    private void CleanupFinishedOneShots()
    {
        for (int i = oneShotVoices.Count - 1; i >= 0; i--)
        {
            OneShotVoice voice = oneShotVoices[i];
            AudioSource source = voice.Source;
            if (source != null &&
                (source.isPlaying || voice.StartedFrame == Time.frameCount ||
                 (AudioListener.pause && !source.ignoreListenerPause)))
                continue;

            ReleaseOneShot(i);
        }
    }

    public void StopBgm()
    {
        if (bgmSource != null) bgmSource.Stop();
    }

    public void Stop(AudioSource source)
    {
        if (source == null) return;
        if (source == bgmSource) { source.Stop(); return; }
        if (!loopVolumes.Remove(source)) return;
        loopSoundIds.Remove(source);
        loopStartedFrames.Remove(source);
        enemyLoopLifetimes.Remove(source);
        source.Stop();
        Destroy(source.gameObject);
    }

    private void CleanupStoppedLoops()
    {
        stoppedLoops.Clear();
        foreach (var pair in loopVolumes)
            if (pair.Key == null || (!pair.Key.isPlaying &&
                (!loopStartedFrames.TryGetValue(pair.Key, out int startedFrame) || startedFrame != Time.frameCount) &&
                !(AudioListener.pause && !pair.Key.ignoreListenerPause)))
                stoppedLoops.Add(pair.Key);
```

```csharp
using System;
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.Serialization;

public class PlayerObj : MonoBehaviour
{
    public SPUM_Prefabs _prefabs;
    public float _charMS;
    private PlayerState _currentState;
    public Vector3 _goalPos;
    [SerializeField, FormerlySerializedAs("isAction")] private bool action;
    public bool isAction
    {
        get => action;
        set
        {
            action = value;
            if (action) StopMovement(false);
        }
    }
    public Dictionary<PlayerState, int> IndexPair = new Dictionary<PlayerState, int>();
    public event Action<PlayerObj> PositionChanged;
    public event Action<PlayerObj> Unavailable;
    public bool IsMoving => movementRoutine != null;
    private Coroutine movementRoutine;
    private bool initialized;
    private bool statePlayed;
    private bool pendingMove;
    private const float ArrivalDistance = .01f;

    private void Start()
    {
        if (!Initialize()) return;
        RefreshPosition();
        if (pendingMove && !action) BeginMovement();
        else if (!action) ChangeState(PlayerState.IDLE);
    }

    private bool Initialize()
    {
        if (initialized) return true;
        if (_prefabs == null) _prefabs = GetComponentInChildren<SPUM_Prefabs>(true);
        if (_prefabs == null || _prefabs._anim == null) return false;
        if (!_prefabs.allListsHaveItemsExist()) _prefabs.PopulateAnimationLists();
        _prefabs.OverrideControllerInit();
        foreach (PlayerState state in Enum.GetValues(typeof(PlayerState)))
            if (!IndexPair.ContainsKey(state)) IndexPair[state] = 0;
        initialized = true;
        return true;
    }

    private void OnEnable()
    {
        if (initialized && pendingMove && !action) BeginMovement();
    }

    private void OnDisable()
    {
        bool resume = IsMoving;
        StopMovement(false);
        pendingMove = resume;
        statePlayed = false;
        Unavailable?.Invoke(this);
    }

    public void SetStateAnimationIndex(PlayerState state, int index = 0) => IndexPair[state] = index;

    // Explicit animation previews may replay the same state on demand.
    public void PlayStateAnimation(PlayerState state)
    {
        if (!Initialize()) return;
        _currentState = state;
        _prefabs.PlayAnimation(state, IndexPair[state]);
        statePlayed = true;
    }

    private void ChangeState(PlayerState state)
    {
        if (_currentState == state && statePlayed) return;
        PlayStateAnimation(state);
    }

    public void SetMovePos(Vector2 pos)
    {
        action = false;
        _goalPos = new Vector3(pos.x, pos.y, 0);
        pendingMove = true;
        if (isActiveAndEnabled && Initialize()) BeginMovement();
    }

    private void BeginMovement()
    {
        StopMovement(false);
        pendingMove = false;
        if (_charMS <= 0f || Vector2.Distance(transform.position, _goalPos) <= ArrivalDistance)
        {
            ChangeState(PlayerState.IDLE);
            return;
        }
        ChangeState(PlayerState.MOVE);
        movementRoutine = StartCoroutine(MoveToGoal());
    }

    private IEnumerator MoveToGoal()
    {
        while (!action)
        {
            if (Time.deltaTime <= 0f) { yield return null; continue; }
            Vector2 current = transform.position;
            Vector2 goal = _goalPos;
            if ((goal - current).sqrMagnitude <= ArrivalDistance * ArrivalDistance || _charMS <= 0f) break;
            Vector2 next = Vector2.MoveTowards(current, goal, _charMS * Time.deltaTime);
            if (next.x > current.x) _prefabs.transform.localScale = new Vector3(-1, 1, 1);
            else if (next.x < current.x) _prefabs.transform.localScale = Vector3.one;
            transform.position = new Vector3(next.x, next.y, transform.position.z);
            RefreshPosition();
            if (next == goal) ChangeState(PlayerState.IDLE);
            yield return null;
        }
        movementRoutine = null;
        if (!action) ChangeState(PlayerState.IDLE);
    }

    private void StopMovement(bool playIdle)
    {
        if (movementRoutine != null) StopCoroutine(movementRoutine);
        movementRoutine = null;
        pendingMove = false;
        if (playIdle && initialized) ChangeState(PlayerState.IDLE);
    }

    // Used by movement and the existing alignment/spawn commands, never polled while idle.
    public void RefreshPosition()
    {
        Vector3 position = transform.position;
        position.z = transform.localPosition.y * .01f;
        transform.position = position;
        PositionChanged?.Invoke(this);
    }
}
```

```csharp
    private void Setup()
    {
        if (dropdown == null)
        {
            dropdown = GetComponent<TMP_Dropdown>();
        }

        if (dropdown == null)
        {
            return;
        }

        if (listRoot == null)
        {
            Transform dropdownList =
                transform.Find("Dropdown List");

            {
                listRoot =
                    dropdownList.GetComponent<RectTransform>();
            }
        }

        {

            listRoot.Find("Viewport/Content");

        {
            return;

            dropdown.options.Count;

        float itemHeight = 28f;

        for (int i = 0; i < content.childCount; i++)
        {
            Transform child =
                content.GetChild(i);

            RectTransform item =
                child.GetComponent<RectTransform>();

            if (item == null)
            {
                continue;
            }

            bool hasOption =
                i < optionCount;

            child.gameObject.SetActive(hasOption);

            if (!hasOption)
            {
                continue;
            }

            item.anchorMin = new Vector2(0f, 1f);
            item.anchorMax = new Vector2(1f, 1f);
            item.pivot = new Vector2(0.5f, 1f);
            item.sizeDelta = new Vector2(0f, itemHeight);
            item.anchoredPosition =
                new Vector2(0f, -itemHeight * i);

            TextMeshProUGUI label =
                child.GetComponentInChildren<TextMeshProUGUI>(true);

            if (label != null)
            {
                label.text = dropdown.options[i].text;
                label.color = Color.black;
                label.raycastTarget = false;
            }

            Toggle toggle =
                child.GetComponent<Toggle>();

            if (toggle != null)
            {
                toggle.enabled = false;
            }

            Button button =
                child.GetComponent<Button>();

            if (button != null)
            {
                button.enabled = false;
            }

            Image image =
                child.GetComponent<Image>();

            if (image != null)
            {
                image.raycastTarget = true;
            }

            PersistentTMPDropdownOption option =
                child.GetComponent<PersistentTMPDropdownOption>();

            }

            content.GetComponent<RectTransform>();

                    itemHeight * optionCount

                itemHeight * optionCount
            );
```

```csharp
    private RectTransform dropdownRect;

    private void Awake()
    {
        dropdown = GetComponent<TMP_Dropdown>();
        dropdownRect = transform as RectTransform;
    }

    private void OnEnable()
    {
        dropdown.onValueChanged.AddListener(OnOptionSelected);
    }

    private void OnDisable()
    {
        dropdown.onValueChanged.RemoveListener(OnOptionSelected);
    }

    private void OnOptionSelected(int index)
    {
        UiSoundEvents.Request(UiSoundCue.Confirm);
    }

    public void OnPointerDown(PointerEventData eventData)
    {
        wasExpandedOnPointerDown = dropdown.IsExpanded;
    }

    public void OnPointerClick(PointerEventData eventData)
    {
        if (eventData.button != PointerEventData.InputButton.Left)
            return;

        if (!wasExpandedOnPointerDown && dropdown.IsExpanded)
            UiSoundEvents.Request(UiSoundCue.Click);

        if (wasExpandedOnPointerDown && dropdown.IsExpanded)
            dropdown.Hide();

        wasExpandedOnPointerDown = false;
    }

    private void LateUpdate()
    {
        if (!dropdown.IsExpanded || !Input.GetMouseButtonDown(0))
            return;

        Vector2 pointer = Input.mousePosition;

        // The opening button is handled on pointer click, after pointer down.
        if (Contains(dropdownRect, pointer))
            return;

        Transform list = dropdown.template != null
            ? dropdown.template.parent.Find("Dropdown List")
            : null;

        if (list is RectTransform listRect && Contains(listRect, pointer))
            return;

        dropdown.Hide();
    }

    private static bool Contains(RectTransform rect, Vector2 pointer)
    {
        Canvas canvas = rect.GetComponentInParent<Canvas>();
        Camera camera = canvas != null && canvas.renderMode != RenderMode.ScreenSpaceOverlay
            ? canvas.worldCamera
            : null;

        return RectTransformUtility.RectangleContainsScreenPoint(rect, pointer, camera);
    }
}
```

```csharp
using UnityEngine.EventSystems;

public class UpgradeHover : MonoBehaviour,
    IPointerEnterHandler,
    IPointerExitHandler
{
    [Header("Hover")]
    [SerializeField] private GameObject outLine;
    [SerializeField] private RectTransform hoverTarget;

    [Header("Move")]
    [Tooltip("기본 위치에서 위로 얼마나 올라갈지")]
    [SerializeField] private float targetYValue = 30f;

    [SerializeField] private float upSpeed = 10f;
    [SerializeField] private float downSpeed = 10f;

    [Header("Scale")]
    [SerializeField] private float targetScale = 1.1f;


    private RectTransform visualRect;

    private Vector3 defaultScale;
    private float defaultYValue;

    private bool isHovering;

    // 호버 입력 자체를 막는 용도
    private bool hoverBlocked;

    // 선택 후 현재 커진 상태를 유지하는 용도
    private bool hoverLocked;


    // =========================================================
    // Awake
    // =========================================================

    private void Awake()
    {
        // hoverTarget을 지정하지 않았다면 자기 자신 사용
        visualRect = hoverTarget != null
            ? hoverTarget
            : transform as RectTransform;


        if (visualRect == null)
        {
            Debug.LogError(
                $"{name} : UpgradeHover에 RectTransform이 없습니다."
            );

            return;
        }


        // 원래 크기 저장
        defaultScale =
            visualRect.localScale;


        // 원래 Y 위치 저장
        defaultYValue =
            visualRect.anchoredPosition.y;


        if (outLine != null)
        {
            outLine.SetActive(false);
        }
    }


    // =========================================================
    // OnEnable
    // =========================================================

    private void OnEnable()
    {
        hoverBlocked = false;
        hoverLocked = false;
        isHovering = false;


        RestoreVisual();
    }


    // =========================================================
    // OnDisable
    // =========================================================

    private void OnDisable()
    {
        hoverBlocked = false;
        hoverLocked = false;
        isHovering = false;


        RestoreVisual();
    }


    // =========================================================
    // Update
    // =========================================================

    private void Update()
    {
        if (visualRect == null)
            return;


        // -----------------------------------------------------
        // 선택 후 호버 고정 상태
        //
        // 이미 커진 상태 그대로 유지
        // -----------------------------------------------------

        if (hoverLocked)
        {
            return;
        }


        // -----------------------------------------------------
        // 호버 중
        // -----------------------------------------------------

        if (isHovering && !hoverBlocked)
        {
            MoveUp();
            ScaleUp();
        }

        // -----------------------------------------------------
        // 호버 해제
        // -----------------------------------------------------

        else
        {
            MoveDown();
            ScaleDown();
        }
    }


    // =========================================================
    // Pointer Enter
    // =========================================================

    public void OnPointerEnter(PointerEventData eventData)
    {
        // 선택 후 잠긴 상태라면 아무것도 하지 않음
        if (hoverLocked)
            return;


        // 강제로 호버가 막힌 상태
        if (hoverBlocked)
            return;


        isHovering = true;

        UiSoundEvents.Request(UiSoundCue.Hover);

        }

        if (hoverLocked)
            return;

        if (outLine != null)

            outLine.SetActive(false);
        }

    // 위로 이동
    // =========================================================

        Vector2 position =
            visualRect.anchoredPosition;


        float targetY =
            defaultYValue + targetYValue;


        position.y =
            Mathf.MoveTowards(
                position.y,
                targetY,
                upSpeed * Time.unscaledDeltaTime
            );


        visualRect.anchoredPosition =
            position;
    }

    // =========================================================

        Vector2 position =
            visualRect.anchoredPosition;


        position.y =
            Mathf.MoveTowards(
                position.y,
                defaultYValue,
                downSpeed * Time.unscaledDeltaTime
            );


        visualRect.anchoredPosition =
            position;

    // 확대
    // =========================================================

    // =========================================================

                visualRect.localScale,
                defaultScale,
                downSpeed * Time.unscaledDeltaTime
            );
    }

    // 선택한 카드용

    // 현재 호버 상태 그대로 고정
    //

            outLine.SetActive(true);
```

```csharp
    public void UpgradeIsSelected()

            upgradeUiInfo == null || upgradeUiInfo.upgradeData == null ||
            upgradeUiInfo.upgradeData.id <= 0)

            !selectionButton.IsInteractable())

        PlaySelectEffect();

        // 나머지 카드 FadeOut
        // =====================================================

        foreach (SelectUpgrade sibling in siblingObjects)
        {
            if (!sibling.gameObject.activeInHierarchy)
                continue;


            // -------------------------------------------------
            // 깜빡임 정지
            // -------------------------------------------------

            if (sibling.blinkLevelIcon != null)

                sibling.StopCoroutine(

    // =========================================================
    // 선택 이펙트 재생
    // =========================================================

    private void PlaySelectEffect()
    {
        if (selectEffect == null)
            return;


        // 한번 껐다가 다시 켜서
        // 항상 처음부터 재생
        selectEffect.SetActive(false);
        selectEffect.SetActive(true);


        if (selectEffectParticles == null)
            return;


        foreach (ParticleSystem particle in selectEffectParticles)
        {
            if (particle == null)
                continue;


            particle.Stop(
                true,
                ParticleSystemStopBehavior.StopEmittingAndClear
            );


            particle.Play(true);
        }
    }


    // =========================================================
    // 선택 순서
    //
    // 1. 다른 카드 어두워짐
    // 2. Fade 완료까지 기다림
    // 3. 선택 이펙트 완료까지 기다림
    // 4. 둘 다 완료되면 전체 UI 닫기
    // =========================================================

    private IEnumerator SelectionSequence()
    {
        // -----------------------------------------------------
        // 최소 한 프레임 기다려서
        // ParticleSystem이 정상적으로 재생 상태에 들어가게 함
        // -----------------------------------------------------

        yield return null;


        // =====================================================
        // 1. 다른 카드 FadeOut 완료 기다리기
        // =====================================================

        bool fadeFinished = false;


        while (!fadeFinished)
        {
            fadeFinished = true;


            foreach (SelectUpgrade sibling in siblingObjects)
            {
                if (!sibling.gameObject.activeInHierarchy)
                    continue;


                if (sibling.padeOutCoroutine != null)
                {
                    fadeFinished = false;

                    break;
                }
            }


            yield return null;
        }


        // =====================================================
        // 2. 선택 이펙트가 완전히 끝날 때까지 기다림
        // =====================================================

        bool effectFinished = false;


        while (!effectFinished)
        {
            effectFinished = true;


            if (selectEffectParticles != null &&
                selectEffectParticles.Length > 0)
            {
                foreach (ParticleSystem particle in selectEffectParticles)
                {
                    if (particle == null)
                        continue;


                    // 현재 파티클 또는 자식 파티클이
                    // 아직 살아있으면 기다린다.
                    if (particle.IsAlive(true))
                    {
                        effectFinished = false;

                        break;
                    }
                }
            }


            if (!effectFinished)
            {
                yield return null;
            }
        }


        // =====================================================
        // 3. Fade도 끝남
        //    이펙트도 끝남
        //
        // 이제 전체 UI 닫기
        // =====================================================

        yield return StartCoroutine(
            CloseUpgradeUI()
        );


        selectSequenceCoroutine = null;
    }


    // =========================================================
    // 선택 가능 여부
    // =========================================================

    private void SetSelectionEnabled(bool value)
    {
        selectionEnabled = value;


        if (selectionButton != null)
        {
            selectionButton.interactable =
                value;
        }
    }


    // =========================================================
    // 업그레이드 UI 등장
    // =========================================================

    private IEnumerator UpgredesMomOpen()
    {
        if (upgredesMom == null)
            yield break;


        upgredesMom.SetActive(true);


        float scale =
            upgredesMom.transform.localScale.x;


        while (scale < 1f)
        {
            scale +=
                speed *
                Time.unscaledDeltaTime;


            scale =
                Mathf.Min(
                    scale,
                    1f
                );


            upgredesMom.transform.localScale =
                new Vector3(
                    scale,
                    scale,
                    scale
                );


            yield return null;
        }


        upgredesMom.transform.localScale =
            Vector3.one;
    }


    // =========================================================
    // 전체 업그레이드 UI 닫기
    // =========================================================

    private IEnumerator CloseUpgradeUI()
    {
        if (upgredesMom == null)
            yield break;


        float scale =
            upgredesMom.transform.localScale.x;


        while (scale > 0.06f)
        {
            scale -=
                closeSpeed *
                Time.unscaledDeltaTime;


            scale =
                Mathf.Max(
                    scale,
                    0.06f
                );


            upgredesMom.transform.localScale =
                new Vector3(
                    scale,
                    scale,
                    scale
                );


            yield return null;
        }


        // -----------------------------------------------------
        // 선택 이펙트 종료
        // -----------------------------------------------------

        if (selectEffect != null)
        {
            selectEffect.SetActive(false);
        }


        upgredesMom.transform.localScale =
            Vector3.zero;


        Time.timeScale = 1f;


        upgredesMom.SetActive(false);
    }


    // =========================================================
    // 다른 카드 어둡게
    // =========================================================

    private IEnumerator FadeOut()
    {
        float value = 1f;


        while (value > darknessAmount)
        {
            value -=
                Time.unscaledDeltaTime *
                fadeOutSpeed;


            value =
                Mathf.Max(
                    value,
                    darknessAmount
                );


            // -------------------------------------------------
            // Image
            // -------------------------------------------------

            for (int i = 0; i < _images.Length; i++)
            {
                Color color =
                    originalColors[i];


                color.r *= value;
                color.g *= value;
                color.b *= value;


                // 기존 알파 유지
                color.a =
                    originalColors[i].a;


                _images[i].color =
                    color;
            }


            // -------------------------------------------------
            // Text
            // -------------------------------------------------

            for (int i = 0; i < _texts.Length; i++)
            {
                Color color =
                    originalTextColors[i];


                color.r *= value;
                color.g *= value;
                color.b *= value;


                color.a =
                    originalTextColors[i].a;


                _texts[i].color =
                    color;
            }


            yield return null;
        }


        padeOutCoroutine = null;
    }


    // =========================================================
    // 선택한 레벨 아이콘 효과
    // =========================================================

    private IEnumerator LevelUpAnim()
    {
        if (blinkLevelIcon != null)
        {
            StopCoroutine(
                blinkLevelIcon
            );


            blinkLevelIcon = null;
        }


        int level =
            upgradeUiInfo.upgradeData.upgradeLevel;


        if (level >= levelIcons.Length)
            yield break;


        Color color =
            levelIcons[level].color;


        color.a = 1f;


        levelIcons[level].color =
            color;


        if (level <
            levelIconsParticles.Length &&
            levelIconsParticles[level] != null)
        {
            levelIconsParticles[level].Play();
        }


        yield return null;
    }
```

```csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.InputSystem;
using UnityEngine.Tilemaps;
public class PlayerMove : MonoBehaviour
{
    public static event System.Action<PlayerMove> BecameAvailable;
    public event System.Action<float> DashEnergyChanged;
    [Header("Dash")]
    [SerializeField] private float dashSpeed = 12f;
    [SerializeField] private float dashDuration = 0.2f;
    [SerializeField] private float dashCost = 25f;
    [SerializeField] private float dashRecoveryPerSecond = 20f;
    [SerializeField] private float dashRecoveryDelay = 0.5f;

    public float DashEnergyNormalized => dashEnergy / 100f;
    public bool IsDashing => isDashing;

    private float dashEnergy = 100f;
    private Coroutine dashCoroutine;
    private Coroutine recoveryCoroutine;
    private Coroutine movementCoroutine;
    private static readonly WaitForFixedUpdate PhysicsStep = new WaitForFixedUpdate();
    private Vector2 dashDirection;
    private bool isDashing;
    private InputAction dashAction;
    private PlayerInput playerInput;

    public Vector2 MoveDir
    {
        get
        {
            return moveDir;
        }
        private set
        {
            moveDir = value;
        }
    }

    public Vector2 moveDir;
    private Rigidbody2D playerRb;
    private AnimationController animationController;
    private Coroutine idleCor;
    public float idleDelay;
    public bool canMove = true;
    public float speed = 3;

    [Header("Tilemap Bounds")]
    [SerializeField, Min(0f)] private float boundaryPadding = 0.02f;

    private SpriteRenderer playerSpriteRenderer;

    [Header("Footstep SFX")]
    [SerializeField, Min(0.05f)]
    [Tooltip("이동 중 발소리 재생 간격(초). 값을 줄이면 더 자주 재생됩니다.")]
    private float footstepInterval = 0.18f;
    [SerializeField, Range(0f, 1f)] private float footstepVolume = 1f;
    private static readonly int[] FootstepSoundIds =
    {
        SoundIds.Footstep01, SoundIds.Footstep02, SoundIds.Footstep03,
        SoundIds.Footstep04, SoundIds.Footstep05, SoundIds.Footstep06,
        SoundIds.Footstep07, SoundIds.Footstep08, SoundIds.Footstep09,
        SoundIds.Footstep10, SoundIds.Footstep11
    };
    private static int previousFootstepIndex = -1;
    private float footstepTimeRemaining;
    private Vector2 lastFootstepPosition;

    public void Awake()
    {
        playerInput = GetComponent<PlayerInput>();
        playerRb = GetComponent<Rigidbody2D>();
        animationController = GetComponent<AnimationController>();
        playerSpriteRenderer = GetComponentInChildren<SpriteRenderer>();
        lastFootstepPosition = playerRb != null ? playerRb.position : (Vector2)transform.position;
    }

    private void OnEnable()
    {
        dashEnergy = 100f;
        isDashing = false;
        footstepTimeRemaining = 0f;
        lastFootstepPosition = playerRb != null ? playerRb.position : (Vector2)transform.position;
        if (dashAction == null)
            dashAction = new InputAction("Dash", InputActionType.Button, "<Mouse>/rightButton");
        dashAction.performed += OnDashPerformed;
        dashAction.Enable();
        DashEnergyChanged?.Invoke(DashEnergyNormalized);
        BecameAvailable?.Invoke(this);
    }

    private void OnDisable()
    {
        if (dashAction != null)
        {
            dashAction.performed -= OnDashPerformed;
            dashAction.Disable();
        }
        if (idleCor != null) StopCoroutine(idleCor);
        if (dashCoroutine != null) StopCoroutine(dashCoroutine);
        if (recoveryCoroutine != null) StopCoroutine(recoveryCoroutine);
        if (movementCoroutine != null) StopCoroutine(movementCoroutine);
        idleCor = null;
        dashCoroutine = null;
        recoveryCoroutine = null;
        movementCoroutine = null;
        MoveDir = Vector2.zero;
        isDashing = false;
        if (playerRb != null) playerRb.linearVelocity = Vector2.zero;
    }

    private void OnDestroy() => dashAction?.Dispose();

    private void OnDashPerformed(InputAction.CallbackContext context)
    {
        if (!isActiveAndEnabled || Time.timeScale <= 0f ||
            playerRb == null || animationController == null) return;
        if (playerInput != null && (!playerInput.enabled || !playerInput.inputIsActive)) return;
        TryDash();
    }

    private IEnumerator RecoverDashEnergy()
    {
        yield return new WaitForSeconds(Mathf.Max(0f, dashRecoveryDelay));
        while (dashEnergy < 100f)
        {
            float previousEnergy = dashEnergy;
            dashEnergy = Mathf.MoveTowards(dashEnergy, 100f, dashRecoveryPerSecond * Time.deltaTime);
            if (dashEnergy != previousEnergy)
                DashEnergyChanged?.Invoke(DashEnergyNormalized);
            yield return null;
        }
        recoveryCoroutine = null;
    }

    private IEnumerator Dash()
    {
        float remaining = Mathf.Max(Time.fixedDeltaTime, dashDuration);
        while (isDashing && remaining > 0f)
        {
            playerRb.linearVelocity = dashDirection * dashSpeed;
            KeepInsideTilemapBounds();
            yield return PhysicsStep;
            remaining -= Time.fixedDeltaTime;
        }
        isDashing = false;
        playerRb.linearVelocity = canMove ? MoveDir * speed : Vector2.zero;
        animationController.EndDashAnimation(canMove && MoveDir != Vector2.zero);
        dashCoroutine = null;
    }

    private void TrackMovement()
    {
        if (movementCoroutine == null && playerRb != null &&
            (isDashing || playerRb.linearVelocity.sqrMagnitude > 0f))
            movementCoroutine = StartCoroutine(MovementPhysics());
    }

    private IEnumerator MovementPhysics()
    {
        // Run the first clamp before the next physics simulation.
        KeepInsideTilemapBounds();
        do
        {
            yield return PhysicsStep;
            KeepInsideTilemapBounds();
            PlayFootstepForMovement();
        }
        while (isDashing || playerRb.linearVelocity.sqrMagnitude > 0f);
        movementCoroutine = null;
        footstepTimeRemaining = 0f;
    }

    private void PlayFootstepForMovement()
    {
        if (playerRb == null)
            return;

        Vector2 currentPosition = playerRb.position;
        bool moved = (currentPosition - lastFootstepPosition).sqrMagnitude > 0.000001f;
        lastFootstepPosition = currentPosition;

        if (!canMove || isDashing || Time.timeScale <= 0f || !moved)
        {
            footstepTimeRemaining = 0f;
            return;
        }

        footstepTimeRemaining -= Time.fixedDeltaTime;
        if (footstepTimeRemaining > 0f)
            return;

        footstepTimeRemaining = Mathf.Max(0f,
            footstepTimeRemaining + Mathf.Max(0.05f, footstepInterval));
        if (SoundManager.Instance == null) return;
        SoundManager.Instance.Play(GetRandomFootstepId(), footstepVolume);
    }

    private static int GetRandomFootstepId()
    {
        int index = Random.Range(0,
            FootstepSoundIds.Length - (previousFootstepIndex >= 0 ? 1 : 0));
        if (previousFootstepIndex >= 0 && index >= previousFootstepIndex)
            index++;
        previousFootstepIndex = index;
        return FootstepSoundIds[index];
    }

    private void KeepInsideTilemapBounds()
    {
        if (playerRb == null || StageManager.Instance == null)
            return;

        Tilemap tilemap = StageManager.Instance.backgroundTilemap;
        if (tilemap == null || !tilemap.gameObject.activeInHierarchy)
            return;

        Bounds localBounds = tilemap.localBounds;
        if (localBounds.size.x <= 0f || localBounds.size.y <= 0f)
            return;

        Vector3 localMin = localBounds.min;
        Vector3 localMax = localBounds.max;
        Vector3 worldBottomLeft = tilemap.transform.TransformPoint(
            new Vector3(localMin.x, localMin.y, 0f));
        Vector3 worldTopRight = tilemap.transform.TransformPoint(
            new Vector3(localMax.x, localMax.y, 0f));

        float mapMinX = Mathf.Min(worldBottomLeft.x, worldTopRight.x);
        float mapMaxX = Mathf.Max(worldBottomLeft.x, worldTopRight.x);
        float mapMinY = Mathf.Min(worldBottomLeft.y, worldTopRight.y);
        float mapMaxY = Mathf.Max(worldBottomLeft.y, worldTopRight.y);

        Vector2 spriteExtents = playerSpriteRenderer != null
            ? (Vector2)playerSpriteRenderer.bounds.extents
            : Vector2.zero;
        Vector2 spriteCenterOffset = playerSpriteRenderer != null
            ? (Vector2)(playerSpriteRenderer.bounds.center - transform.position)
            : Vector2.zero;

        float padding = Mathf.Max(0f, boundaryPadding);
        float minX = mapMinX + spriteExtents.x + padding - spriteCenterOffset.x;
        float maxX = mapMaxX - spriteExtents.x - padding - spriteCenterOffset.x;
        float minY = mapMinY + spriteExtents.y + padding - spriteCenterOffset.y;
        float maxY = mapMaxY - spriteExtents.y - padding - spriteCenterOffset.y;

        if (minX > maxX)
            minX = maxX = (mapMinX + mapMaxX) * 0.5f - spriteCenterOffset.x;
        if (minY > maxY)
            minY = maxY = (mapMinY + mapMaxY) * 0.5f - spriteCenterOffset.y;

        Vector2 currentPosition = playerRb.position;
        Vector2 nextPosition = currentPosition + playerRb.linearVelocity * Time.fixedDeltaTime;
        nextPosition.x = Mathf.Clamp(nextPosition.x, minX, maxX);
        nextPosition.y = Mathf.Clamp(nextPosition.y, minY, maxY);

        playerRb.linearVelocity = (nextPosition - currentPosition) / Time.fixedDeltaTime;
    }

    private void TryDash()
    {
        bool interruptingAttack = animationController.IsBasicAttacking;
        if (isDashing || dashEnergy < dashCost || (!canMove && !interruptingAttack))
            return;

        if (interruptingAttack)
            canMove = true;

        dashDirection = MoveDir.sqrMagnitude > 0f
            ? MoveDir.normalized
            : (transform.localScale.x < 0f ? Vector2.left : Vector2.right);

        dashEnergy -= dashCost;
        DashEnergyChanged?.Invoke(DashEnergyNormalized);
        isDashing = true;
        playerRb.linearVelocity = dashDirection * dashSpeed;
        animationController.StartDashAnimation();
        SoundManager.Instance?.Play(SoundIds.Dash);
        if (recoveryCoroutine != null) StopCoroutine(recoveryCoroutine);
        recoveryCoroutine = StartCoroutine(RecoverDashEnergy());
        dashCoroutine = StartCoroutine(Dash());
        TrackMovement();
    }
    
    public void Move(InputAction.CallbackContext context)
    {
        // Disabling PlayerInput cancels actions after the player becomes inactive.
        if (!isActiveAndEnabled) return;
        MoveDir = context.ReadValue<Vector2>();

        if (isDashing)
            return;

        if (canMove && context.performed)
        {
            playerRb.linearVelocity = MoveDir * speed;
            animationController.Move(true);
            
            if (MoveDir.x != 0f)
                transform.localScale = new Vector3(
                    Mathf.Sign(MoveDir.x) * Mathf.Abs(transform.localScale.x),
                    transform.localScale.y,
                    transform.localScale.z
                );
        }
        
        if (!canMove)
        {
            Debug.Log("canMove");
            animationController.Move(true);
            playerRb.linearVelocity = Vector2.zero;
        }
        
        if(context.canceled)
        {
            Debug.Log("cancel");
            SetIdleDelayed();
            playerRb.linearVelocity = Vector2.zero;
        }
        TrackMovement();
    }

    public void StopMove(int canIMove)
    {
        if (!isActiveAndEnabled)
        {
            canMove = canIMove >= 1;
            return;
        }
        if (canIMove < 1)
        {
            if (dashCoroutine != null) StopCoroutine(dashCoroutine);
            dashCoroutine = null;
            isDashing = false;
        }

        if (canIMove >= 1)
        {
            canMove = true;
            if (isDashing)
                return;
            if (MoveDir != Vector2.zero)
            {
                playerRb.linearVelocity = MoveDir * speed;
                animationController.Move(true);

                if (MoveDir.x != 0f)
                    transform.localScale = new Vector3(
                        Mathf.Sign(MoveDir.x) * Mathf.Abs(transform.localScale.x),
                        transform.localScale.y,
                        transform.localScale.z
                    );            
            }
        }
        else
        {
            playerRb.linearVelocity = Vector2.zero;
            SetIdleDelayed();
            canMove = false;
        }
        TrackMovement();
    }
    
    private void SetIdleDelayed()
    {
        if (isActiveAndEnabled && idleCor == null)
            idleCor = StartCoroutine(IdleDelayCor());
    }

    private IEnumerator IdleDelayCor()
    {
        yield return new WaitForSeconds(idleDelay);
        if (MoveDir == Vector2.zero)
        {
            animationController.Move(false);
        }
        idleCor = null;
    }
}
```
